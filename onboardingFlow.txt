14. Paywall
CTA
Unlock My Plan (teaser image - no real plan generated yet)
Triggers subscription paywall.
Backend Data Model Recommendation
Avoid strict ENUM types.
Store normalized strings instead.
Example
fitness_goals: string[]
motivations: string[]
focus_areas: string[]
Advantages
Frontend labels can change without backend updates
Easier to add new options
Supports A/B testing
Reduces API breaking changes
Normalization Example
Frontend label = Build Muscle
Stored value = build_muscle
